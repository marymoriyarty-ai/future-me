# future-me

A personal project for leaving messages, voice notes, and meaningful moments behind for your future self.

> letters, voice, capsules and more .... just for your future self

## Overview

`future-me` is a concept-driven app and archive for preserving thoughts, memories, and intentions across time. The idea is simple: create a space where you can write letters, record voice capsules, and save meaningful experiences that you can revisit later.

Whether it is a note to your future self, a reflection from today, or a voice memory you want to keep safe for tomorrow, this project is designed to turn personal moments into something lasting.

## Why this project exists

We often think about the future, but not always in a way that leaves a trace behind. `future-me` aims to create a thoughtful digital ritual for:

- writing letters to your future self
- recording voice memories and reflections
- collecting small capsules of time, emotion, and intention
- preserving personal context that may matter more later than it does now
